A one-line joke about cats, for the make.fun bounty "The One-Line Cat Joke That Lands". The program writes a single 119-character line to `/output/entry.txt`: the cat's daily gift, reframed as a performance review of its owner's hunting skills — a review the owner fails in exactly the same way.

## Run it

```sh
python3 main.py
```
